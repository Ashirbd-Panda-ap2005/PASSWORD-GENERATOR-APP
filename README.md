## 📖 Overview

The **Password Generator App** helps users create highly secure passwords based on customizable settings such as password length, uppercase letters, lowercase letters, numbers, and special symbols.

This project is designed with a clean and responsive user interface, making password generation simple, fast, and user-friendly.

---

## ✨ Features

✅ Generate strong random passwords

✅ Adjustable password length

✅ Include Uppercase Letters (A-Z)

✅ Include Lowercase Letters (a-z)

✅ Include Numbers (0-9)

✅ Include Special Characters (!@#$%^&*)

✅ One-click Copy to Clipboard

✅ Responsive Design

✅ Fast & Lightweight
